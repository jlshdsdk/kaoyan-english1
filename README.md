# 考研英语一真题带学

网站：https://jlshdsdk.github.io/kaoyan-english1/

保留原站的 1998—2025 年、133 个模块与原英文内容。正文、题干、选项、写作要求和范文按英文句子显示对应中文；原有段落分组保留。

## 阅读与查词

- 点击高亮词、短语，或双击普通英文单词，查询当前原句。手动输入时优先查找当前模块中的例句。
- 经核对的 511 个核心词和短语显示「本句义」。词义随原句保存，同词不同语境可以更新为当前句。
- 普通单词若有唯一的词典义与本句译文直接对应，会显示「译文对应义（参考）」。这种匹配不等同于人工核对；没有可靠对应时显示原句、译文与通用词典义。
- 生词库保存查询词、词义类型、完整原句及译文、年份和题型。旧词条在打开生词库时尝试匹配并更新原句译文。
- 查词和阅读不需要翻译服务或 API key。在线英文词典、发音和手动配置的 Supabase 同步仍为可选功能。

## 大题学习标记

每篇阅读文章、每篇作文，以及完形、新题型、翻译的整道大题均有独立的「未学习／已学习」按钮，共 242 道大题。点为已学习时记录当天的本地日期，按钮下方的日期可直接修改并自动保存。再次点击可改回未学习并清除该次日期。

这些标记与每日打卡独立，不会跨天重置。刷新、关闭后重新打开网站仍会恢复同一浏览器中的记录。数据存储键为 `ky_study_marks`，用 `年份:题型:大题序号` 标识题目，与词库版本无关；每条记录包含 `studied`、`date` 和 `updatedAt`。

导出 JSON 包含学习标记，导入按每道题的更新时间保留较新的记录；旧备份不包含此字段时不会清除已有标记。已配置的 Supabase 手动同步也包含 `study_marks`，无需增加数据库字段。浏览器数据被清除或更换设备时，需通过备份导入或配置好的同步恢复。

## 部署文件

这是多文件静态站点，无需服务器或运行时构建。GitHub Pages 使用 `main` 分支根目录。必须一起部署：

```text
index.html
styles.css
manifest.js
study.js
learning.js
app.js
data/1998.json ... data/2025.json
data/dictionary.json
data/lookup-index.json
```

首页只读取资源清单；点击年份后加载该年份的 JSON，首次查词时加载词典，跨模块查找原句时才读取查词索引。已加载的年份与词典在当前页面内复用。文件 URL 带有内容版本号；更改数据或运行时代码时请同步更新 `manifest.js` 的版本与 `index.html` 中的版本参数。

学习记录继续使用原来的浏览器存储键，发布新版本不会主动清空已有收藏、生词和打卡。导出 JSON 可以备份学习记录与显示偏好。Supabase 同步打卡、每日完成项、收藏与大题学习标记。

## 内容维护

每个年份文件由原模块对象组成。双语数组保留英文和译文，并附加句子元数据：

```json
["Original English.", "对应中文。", {"sentences": [
  {"id": "稳定的句子编号", "en": "Original English.", "zh": "对应中文。", "glossary": {"word": "本句中的中文含义"}}
]}]
```

题干和翻译题的句子位于 `sentences`，题目要求的句子位于 `directionSentences`。`glossary` 是逐句词义，不应将某一词义无差别复制到所有句子。中文补充说明使用 `note` 或作文 `image_desc`，以免与原文翻译混在一起。

本次修订保留准确的已有译文，纠正发现的漏译、语义偏差和对应错位；现有英文自身存在疑点时，保留原文并加说明。译文和自动对应的参考词义仍可继续校订。
